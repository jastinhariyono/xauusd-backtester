# XAUUSD Backtester

Windows app for manual XAUUSD (gold) backtesting. Replay gold charts candle by candle, place trades on the chart,
and review every trade with entry, exit and after-exit screenshots.

**[Download the free trial](https://github.com/jastinhariyono/xauusd-backtester/releases/latest/download/XAUUSD-Backtester-Trial.zip)**
(Windows 10 / 11, all features, XAUUSD data from the last 6 months, no license needed).

1. Extract the zip to a normal folder (for example Documents).
2. Double-click `XAUUSD-Backtester-Trial.exe`. If Windows shows a blue "Windows protected your PC" screen, click
   **More info**, then **Run anyway** (the app is not digitally signed yet).
3. Wait about 30 seconds. The app opens in your browser at `http://localhost:8000`.

The zip also contains the user guide (English and Indonesian) and an illustrated installation guide.
